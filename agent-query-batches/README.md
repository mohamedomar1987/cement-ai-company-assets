3. Real public engineering or official policy source, checked for applicability and recency.
4. Concrete free-first resolution and conditional product fit; no claim of protected-file access.
5. Machine-readable schema, unique ID/normalized-question test and actual file readback.
6. No automatic financial action, no search-ranking manipulation and no forged reviews, endorsements or sources.
